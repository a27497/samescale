## 与定稿的剩余差距及风险

视觉主题、Shell、核心信息结构、对称对照、Master–Detail 和五步阅读保持冻结设计方向，但不宣称像素级一致。截图参考的原尺寸不同，等比对照用于人工核查结构和比例。

| 页面 | 真实业务适配带来的差异 |
| --- | --- |
| Home | 无真实搜索 API 或跨产品近期指标，使用真实离线 CTA 和三入口；不展示示例近期运行表。真实内容较少，整页更短。 |
| Run Detail | 不补造测试通过数、进度、Agent confidence、时间和沙箱断言；显示实际评分、摘要、原始事件和身份。卡片高度随真实文本变化。 |
| Diagnosis | 实际只有一个簇、三个失败运行；不补造空簇、根因概率或因果链。原始 trace pattern、事实／假设和限制文本导致不同的密度和高度。 |
| Regression | 实际两个不可比原因、六个维度，保留接口原始／合格／总体指标边界；不补造八维环境明细、补跑或胜出能力。 |
| Public Demo | 五步由实际保存摘要支持，不增加 certainty、SPEC attestation、audit/export-ready、复制实验包等示例能力；保留详情与产物读取边界。 |

共享 Shell 移除无实现的全局搜索、账号和 Spec／通知动作；运行入口只在具体真实运行上下文中出现。字体使用现有系统回退，没有新增网络字体，因此中字字形／行距与设计稿略有差异。原始英文证据在中文 UI 中保留属于证据契约；长 ID 和摘要按实际内容换行。人工需确认这些真实内容下的密度、留白和比例；没有已知技术阻塞，但**人工视觉通过尚未宣称**。私有环境真实持久化、付费执行、非 Chromium 和完整读屏验收不在本次观察结果中。
