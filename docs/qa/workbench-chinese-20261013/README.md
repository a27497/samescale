## 本次修正

首页不再写死“有独立验收记录”。实验概况不包含独立验收结论，因此页面通过已有
运行列表与详情接口，只读检查实际保存的 verifier_passed 值。明确的 true 或 false
都表示存在结论；空值不能从运行结束、规范化结果或分数推断为通过。

每个示例实验分别显示：有结论时报告有结论的数量，并说明不代表全部通过；没有
结论时显示“尚未核验”；读取失败时说明暂时无法确认；没有保存运行时说明暂无记录。
只读取每个实验前 50 条运行，详情最多并发 5 条，并明确显示未读完的范围。离开页面后
停止安排后续批次。示例与个人运行保持分离，入口继续使用原始实验 ID。

Harness 注册表将 Direct model adapter 展示为“直接模型适配器”。完整实现名（包括
model_lane）、原始名称、Harness ID 和版本保留在默认收起的技术详情中；原值可查看和复制。
没有重命名服务端注册表、实现包或历史运行身份。

原先随 PR 加入的 19 个 PNG、1 个截图对照 HTML 和 6 个 QA JSON 已逐字节移到仓库外归档。
本目录只保留文字验收说明。功能分支历史在用户授权范围内重写，新增提交不再包含
这些文件，而不是在后续提交中只做删除。以准确旧分支 SHA 作为 force-with-lease 的
前提更新同一个 PR；main 和其他工作树不作为历史改写目标。

## 保留的首轮展示契约

核心与高级页面以中文为主，状态名称、上下文和颜色集中维护。缺失、未知、未运行、
未核验和基础设施失败各自保持含义。运行结束、事件完成、配置存在、规划检查通过
都不能替代独立任务验收。原始状态保留在悬停提示或收起的技术详情中。

核心就绪度区分冻结发布与当前工作区证据；读取失败提供下一步引导。总览部分读取
失败保持未知计数，不作为空列表或零结果。Agent 自报与独立验收分开，安全下载保留
原始 API 值。未知来源文本提供原文入口，不生成新的翻译结论或根因判断。

首轮观察：原首页只有个人运行空状态；修改后能进入来源明确的示例。总览、运行控制、
JudgeLab、就绪度及注册表页原先有英文说明和机器码，修改后使用中文标签与引导。
固定示例的英文消息保存在展开区。以上是文字描述，不引用仓库中的图片或截图文件。
