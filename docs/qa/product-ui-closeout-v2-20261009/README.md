显示名称只用于 UI。导航、服务端搜索、引用与下载仍使用原始身份；同名实验和同任务运行
通过必要的区分信息与识别码区分，列表中发生短识别码冲突时延长识别码。显示“第 N 次”
使用 `repeat_index + 1`，原始从零开始的 index 与 attempt 在技术详情和 JSON 中保持不变。
未知配置不猜测模型身份，使用中性配置标签及识别码。

共享技术详情可以查看并复制完整原值；复制失败时保留可选取的原文并说明手动复制方式。
机器状态仍保留原 data-status、title、辅助技术名称和键盘焦点代码；焦点提示不改变标签
所在行的布局。未知状态保持中性，不用颜色猜测验收结果。

首轮 Real/Fake 隔离、任务验收／Verifier 进程语义、FILE_CHANGE／最终工作区区分，以及
NOT_COMPARABLE／PARTIALLY_COMPARABLE 方向规则继续通过测试。历史中文概览不解析自由
文本：只匹配明确的 tool／field_path，检查数值类型、分母相加、证据层级、正式资格以及
重复字段冲突，并要求引用存在于返回目录；条件不满足时不生成此类概览。摘要一致性仍不代表来源认证或因果证明。

## 交互修正

- 实验选择器按名称阅读；预填原 ID 不在有限列表中或列表读取失败时仍正确保持选择。
  可以在展开区查看／输入原 ID，不将“已预填”误显示成“未选择”。
- 同一页面改变运行选择或标签时保持视口。真正的页面跳转回到顶部，历史返回等待异步
  证据与公开产物准备结束，再恢复展开状态和滚动位置；恢复记录仅在当前页面内存中存在。
- Run 从 Demo 进入时能返回 Demo；从实验运行列表进入时保留原筛选 URL 和滚动位置。
- Run 404 明确显示“运行记录不存在”，提供实验列表入口，不展示替代记录。Trace 暂不可用
  时保留独立验收；重试和后端完整性边界保持原有行为。
- 实验列表有加载更多；运行列表可搜索已加载的任务、配置、显示名称或原 ID；Trace 初始
  显示前 8 条，可查看全部。事件正文、复制字段与原始 JSON 按需展开。缺失的引用也使用简短标签，完整原值保留可复制；null 原文以“未报告”显示，不堆叠缺失机器码。
- 实验详情读取增加请求代际检查，防止切换身份后晚到的旧响应覆盖新记录。
