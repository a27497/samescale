## 项目介绍

**HarnessLab：面向 AI Coding 的证据诊断与回归 Agent 工作台。**

当 Coding Agent 在工程任务中失败时，系统让调查模型查询受控运行证据、核对失败与比较
结果，输出可引用的事实、原因假设和信息不足的限制，并保存调查状态和待审阅的回归方案。
模型提出动作，应用负责校验范围、执行工具、记录预算和验证引用。

技术栈：Python、FastAPI、Pydantic、SQLAlchemy/PostgreSQL、LangGraph、Vue/TypeScript、Docker。

## 60 秒项目介绍

> HarnessLab 是一个面向 AI Coding 的证据诊断与回归 Agent 工作台。它处理的问题是：
> Coding Agent 任务失败后，怎样根据实际运行记录调查，而不是只让模型猜原因。
> 调查模型可以选择六类只读工具，查询运行、比较结果和检查证据；应用负责限制访问范围、
> 验证引用并记录预算。调查状态保存在 PostgreSQL 中，恢复时不会重置已消耗预算。
> 最终输出有证据支持的事实、假设和限制，以及待审阅的回归方案，审批不会自动执行实验。
> 项目已有一条真实模型完成的调查记录。现场交互使用关闭真实调用的 Fake 会话，真实结果
> 单独通过冻结证据展示。项目由 AI 辅助开发，个人贡献需要与实际参与记录对应。
