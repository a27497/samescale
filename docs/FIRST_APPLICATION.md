## 项目介绍

**HarnessLab：面向 AI Coding 的证据诊断与回归 Agent 工作台。**

当 Coding Agent 在工程任务中失败时，系统让调查模型查询受控运行证据、核对失败与比较
结果，输出可引用的事实、原因假设和信息不足的限制，并保存调查状态和待审阅的回归方案。
模型提出动作，应用负责校验范围、执行工具、记录预算和验证引用。

技术栈：Python、FastAPI、Pydantic、SQLAlchemy/PostgreSQL、LangGraph、Vue/TypeScript、Docker。

## 简历能力摘要草稿

- 基于 FastAPI 和 LangGraph 构建有界调查链路，接入真实模型的结构化工具决策；六类只读
  工具限定在实验、任务和运行范围内，宿主校验参数、引用和结构化事实，保留无法判断的结果。
- 使用 PostgreSQL 持久化调查状态、动作预留和用量，在恢复时保留已消耗预算；方案审批
  绑定作用域和内容摘要，方案变更使原审批失效，保存审批不触发实验执行。
- 将受控执行、不可变证据和调查结果串联为工程案例，保留 Fake/MockTransport 无密钥回归；
  一条接受的真实会话完成 4 次模型决策和 9 次工具调用，最终事实由应用按证据验证。

简历空间有限时，保留前两条，再补本人真正完成的一项测试、修复或设计取舍。不要用测试
总数代替贡献说明；没有对照证据时，不写准确率、效率提升或成本下降比例。
