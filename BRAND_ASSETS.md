establishes copy provenance, not an independent copyright/typography-rights

layout, favicon or product interaction is changed here.

upstream MIT license. They are not SameScale-original artwork or covered by a
new brand reservation. The CSS font-family names reference installed system
fonts; this repository contains no font binaries or remote font loader.
The website's separately licensed fonts/icons are outside this change.
